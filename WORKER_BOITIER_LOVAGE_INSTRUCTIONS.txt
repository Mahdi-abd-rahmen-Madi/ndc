Use the following helper to detect whether the Lovage stage is active and
whether it is `sans_plot`:

```python
def is_lovage_stage_active(input_data: dict) -> bool:
    lv = input_data.get("boitier_lovage") or input_data.get("lovage_equipment") or {}
    ct = str(input_data.get("calculation_type") or "").lower()
    return (
        (isinstance(lv, dict) and bool(lv.get("enabled")))
        or input_data.get("is_lovage") is True
        or "lovage" in ct.split("_")
    )

def resolve_lovage_sans_plot(input_data: dict) -> bool:
    lv = input_data.get("boitier_lovage") or input_data.get("lovage_equipment") or {}
    st = input_data.get("structure_lovage") or {}
    for val in (
        lv.get("sans_plot"),
        (not lv["with_plot"]) if isinstance(lv.get("with_plot"), bool) else None,
        input_data.get("lovage_sans_plot"),
        (not input_data["lovage_with_plot"]) if isinstance(input_data.get("lovage_with_plot"), bool) else None,
        st.get("sans_plot"),
        (not st["with_plot"]) if isinstance(st.get("with_plot"), bool) else None,
    ):
        if val is True:
            return True
        if val is False:
            return False
    ancrage = str(lv.get("ancrage") or "").strip().lower()
    if ancrage == "dallettes":
        return True
    if ancrage in ("beton", "metallique"):
        return False
    ct = str(input_data.get("calculation_type") or "").lower()
    return "lovage_sans_plot" in ct
```

3. WIND CALCULATION (EN 1991-1-4 / EC1) — BOITIER DE LOVAGE (+ GPS + MDEA)
--------------------------------------------------------------------------------
A. Aerodynamic Drag Coefficients (MANDATORY):
  - Boîtier de lovage:
      * Frontal drag coefficient: `Cf,front = 1.47`
      * Lateral drag coefficient: `Cf,lat   = 1.19`
  - Convertisseur MDEA (when `boitier_lovage.has_mdea == true` or `mdea.enabled == true`):
      * Default dimensions: `338 x 295 x 140 mm` (`H x W x D`), weight: `10.0 kg`
      * Frontal drag coefficient: `Cf,front = 1.46`
      * Lateral drag coefficient: `Cf,lat   = 1.12`
  - Antenne GPS (when `boitier_lovage.has_gps == true` or `gps.enabled == true`):
      * Catalog specs (for Table 0 display):
          - NOKIA `FYGC 474074A` / `FYGB 472748A`: `Ø95 x 72.5 mm`, `0.154 kg` (154 g)
          - ERICSSON `KRE 101 2395/2`: `Ø78 mm`, `0.225 kg` (225 g)
      * Negligible weight in FEA (`PE_gps = 0.0 daN`)
      * Wind force neglected (`Fw_gps = 0.0 daN`); included for report title/description/Table 0.
  - Mast drag coefficient:    `Cf,mat   = 1.00` (tube Ø88.9 mm -> `d = 0.088 m`)
  - Structural factor:        `cs * cd  = 1.00`

B. Peak Velocity Pressure `qp(z)` (daN/m²):
  - Reference height `z`:
      * AVEC PLOT: `z = building_height_m + 0.50 + hauteur_mat_m`
      * SANS PLOT: `z = building_height_m + hauteur_mat_m`
  - Standard EC1 chain (clamped to `z_min` per terrain category):
      * `kr    = 0.19 * (z0 / 0.05) ** 0.07`
      * `cr(z) = kr * ln(z / z0)`
      * `Vm    = cr(z) * 1.0 * Vb`
      * `Iv(z) = 1.0 / ln(z / z0)`
      * `qp    = (1 + 7 * Iv(z)) * 0.5 * 1.25 * Vm² / 10.0`  (daN/m²)

C. Wind Forces & Combined Mast Load Application (SAME POINT ON MAST):
  - Mast distributed wind load (daN/ml):
      `Fw,mat = 1 * 1.0 * 0.088 * qp`
  - Boîtier de lovage projected areas & forces:
      * `A_front_lovage = (H_mm * W_mm) / 1e6`  (m²)
      * `A_lat_lovage   = (H_mm * D_mm) / 1e6`  (m²)
      * `Fw,Frontale_lovage = qty_lovage * 1.47 * A_front_lovage * qp`
      * `Fw,Latéral_lovage  = qty_lovage * 1.19 * A_lat_lovage   * qp`
      * `PE_lovage          = qty_lovage * weight_lovage_kg`
  - Convertisseur MDEA projected areas & forces (when active):
      * `A_front_mdea = (338 * 295) / 1e6 = 0.0997 m²`
      * `A_lat_mdea   = (338 * 140) / 1e6 = 0.0473 m²`
      * `Fw,Frontale_mdea = qty_mdea * 1.46 * A_front_mdea * qp`
      * `Fw,Latéral_mdea  = qty_mdea * 1.12 * A_lat_mdea   * qp`
      * `PE_mdea          = qty_mdea * 10.0`
  - Antenne GPS (when active):
      * `PE_gps = 0.0 daN` (negligible weight), `Fw_gps = 0.0 daN`
  - Combined Robot Load Application (applied at the SAME point on `TRON 88x3.2` mast):
      * `PE_total = PE_lovage + PE_mdea`  (`FZ = -PE_total` daN)
      * `Fw,Frontale_total = Fw,Frontale_lovage + Fw,Frontale_mdea`  (applied in `Vent ±X`)
      * `Fw,Latéral_total  = Fw,Latéral_lovage  + Fw,Latéral_mdea`   (applied in `Vent ±Y`)


4. ROBOT FEA MODELING (AVEC PLOT vs SANS PLOT)
--------------------------------------------------------------------------------
A. Structural Sections & Geometry:
  - Mât principal:
      * Section: `TRON 88x3.2` (tube Ø88.9 mm, épaisseur 3.2 mm, steel S235)
      * Length:  `hauteur_mat_m` (default `1.50` m / 1500 mm)
  - Plot métallique:
      * AVEC PLOT (`sans_plot == False`):
          - Section: `TCAR 150x5` (steel S235)
          - Length:  `0.50` m
          - Fixed support at base of plot (`Z = 0.0 m`)
          - Baseplate / assemblage Mât/Plot verified in Robot
      * SANS PLOT (`sans_plot == True`):
          - NO plot bar (`TCAR 150x5` omitted completely)
          - Mât principal `TRON 88x3.2` anchored directly (fixed support at `Z = 0.0 m`)
          - NO plot verification, NO assemblage Mât/Plot verification

B. Load Cases (NO LADDER / NO `CH` CHUTE D'HOMME ON BOÎTIER DE LOVAGE):
  - Boîtier de Lovage does NOT support a ladder (`echelle`) or fall-arrest
    anchor (`CH` / chute d'homme), regardless of mast height or plot type.
    Ignore any legacy `echelle` field on `boitier_lovage` and NEVER add the
    `+15 daN` ladder weight or `CH` accidental load case.
  - Always model strictly 6 load cases:
      * Case 1 — `PP` (Poids propre, Permanent): self-weight of structure
      * Case 2 — `PE` (Poids équipements, Permanent): `FZ = -PE_total` daN on mast
      * Cases 3–6 — Wind cases (`Vent +X`, `Vent -X`, `Vent +Y`, `Vent -Y`):
          - `Vent +X`: mast `Fw,mat` (+X) + equipment `Fw,Frontale_total` (+X)
          - `Vent -X`: mast `Fw,mat` (-X) + equipment `Fw,Frontale_total` (-X)
          - `Vent +Y`: mast `Fw,mat` (+Y) + equipment `Fw,Latéral_total` (+Y)
          - `Vent -Y`: mast `Fw,mat` (-Y) + equipment `Fw,Latéral_total` (-Y)

C. Load Combinations:
  - Standard Eurocode 1 / Eurocode 3 ELU and ELS combinations (`PP`, `PE`,
    `Vent ±X`, `Vent ±Y`), matching the RRH/RRU support combination matrix.

D. Verifications & Exports:
  - Always (both AVEC PLOT and SANS PLOT):
      1. 3D model screenshot -> `lovage_screenshot` (`job_{id}_lovage_3d_view.jpg`)
      2. Load table & combinations screenshot -> `lovage_tableau_charges` (`job_{id}_lovage_tableau_charges.png`)
      3. Steel verification ratios screenshot (ELU/ELS) -> `lovage_verification_screenshot` (`job_{id}_lovage_verification.jpg`)
      4. Mât principal `TRON 88x3.2` RTF calculation note -> `lovage_note_mat` (`job_{id}_lovage_note_mat.rtf`)
      5. Support reactions text file -> `lovage_reactions_file` (`job_{id}_lovage_reactions.txt`)
  - ONLY when AVEC PLOT (`sans_plot == False`):
      6. Plot `TCAR 150x5` RTF calculation note -> `lovage_note_plot` (`job_{id}_lovage_note_plot.rtf`)
      7. Assemblage Mât/Plot RTF calculation note -> `lovage_assemblage_note` (`job_{id}_lovage_assemblage_note.rtf`)
