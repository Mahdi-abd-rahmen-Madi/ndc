================================================================================
ROBOT STRUCTURAL ANALYSIS WORKER - FH MAST SECTION (DUAL PROFILE: Ø114.3x3.6 DEFAULT + Ø88.9x3.2)
================================================================================

1. SUMMARY
--------------------------------------------------------------------------------
The FH support mast now defaults to `TRON 114x3.6` (Ø114.3 mm, 3.6 mm wall
thickness, `114.3*3.6`, d = 0.1143 m), while still supporting `TRON 88x3.2`
(Ø88.9 mm, 3.2 mm wall thickness, d = 0.0889 m) whenever explicitly requested
in `input_data`.

NOTE:
- RRH and Boîtier de Lovage support masts remain `TRON 88x3.2` — do NOT change them.
- RRU support masts remain `TRON 88x2.5` — do NOT change RRU.


2. REQUIRED WORKER CHANGES (FH ONLY)
--------------------------------------------------------------------------------
1. Resolve FH mast profile dynamically from `input_data` with `TRON 114x3.6` as
   the default:
     ```python
     FH_MAST_PROFILES = {
         "TRON 114x3.6": {
             "mast_section": "TRON 114x3.6",
             "diam_mm": 114.3,
             "thickness_mm": 3.6,
             "mast_d_m": 0.1143,
             "mast_t_m": 0.0036,
         },
         "TRON 88x3.2": {
             "mast_section": "TRON 88x3.2",
             "diam_mm": 88.9,
             "thickness_mm": 3.2,
             "mast_d_m": 0.0889,
             "mast_t_m": 0.0032,
         },
     }

     def resolve_fh_mast_profile(input_data: dict) -> dict:
         fh_struct = input_data.get("structure_fh") or {}
         struct = input_data.get("structure") or {}
         raw = str(
             fh_struct.get("mast_section")
             or (struct.get("mast_section") if input_data.get("is_fh") else "")
             or ""
         ).strip().lower().replace(",", ".")
         if raw and ("88x3.2" in raw or "88.9*3.2" in raw or "88.9x3.2" in raw or "88*3.2" in raw):
             return dict(FH_MAST_PROFILES["TRON 88x3.2"])
         return dict(FH_MAST_PROFILES["TRON 114x3.6"])
     ```
2. Robot Bar Section Assignment (FH model):
   - Assign `profile["mast_section"]` (`TRON 114x3.6` by default, or `TRON 88x3.2`
     if requested) to the FH main mast bar in Robot Structural Analysis.
   - If you use a base `.rtd` template file for FH, ensure both `TRON 114x3.6`
     and `TRON 88x3.2` profiles are available in the Robot section catalog, and
     update the bar section dynamically at runtime before running the analysis.
3. Wind Load & Geometry Constants (FH only):
   - Use `profile["mast_d_m"]` and `profile["mast_t_m"]` dynamically instead of
     hardcoded `88.9` / `0.088` / `3.2` constants:
       * `TRON 114x3.6` (default): `Fw,mat = 1 * 1.0 * 0.1143 * qp`, `t = 0.0036 m`
       * `TRON 88x3.2` (when requested): `Fw,mat = 1 * 1.0 * 0.0889 * qp`, `t = 0.0032 m`
   - Ensure steel verification and assemblage verification use the resolved
     diameter and wall thickness.
4. `result_data` Payload:
   - Return the resolved section, diameter, and thickness in
     `result_data["fh"]["structure_params"]` (and top-level `structure_params`
     for standalone FH):
     Default (`TRON 114x3.6`):
     ```json
     "structure_params": {
       "mast_section": "TRON 114x3.6",
       "mast_d_m": 0.1143,
       "mast_t_m": 0.0036
     }
     ```
     Secondary (`TRON 88x3.2`):
     ```json
     "structure_params": {
       "mast_section": "TRON 88x3.2",
       "mast_d_m": 0.0889,
       "mast_t_m": 0.0032
     }
     ```


3. VERIFICATION
--------------------------------------------------------------------------------
- Run an FH job (and an `antenna_with_fh` job) with default `TRON 114x3.6`:
  * Robot 3D view legend shows `TRON 114x3.6` on the FH mast.
  * FH mast wind force uses `Fw = 1 * 1 * 0.1143 * qp`.
  * Exported FH mast RTF calculation note verifies `TRON 114x3.6`.
  * `result_data["fh"]["structure_params"]["mast_section"] == "TRON 114x3.6"`.
- Run an FH job with `structure_fh.mast_section = "TRON 88x3.2"`:
  * Robot 3D view legend shows `TRON 88x3.2` on the FH mast.
  * FH mast wind force uses `Fw = 1 * 1 * 0.0889 * qp`.
  * Exported FH mast RTF calculation note verifies `TRON 88x3.2`.
  * `result_data["fh"]["structure_params"]["mast_section"] == "TRON 88x3.2"`.
- Confirm RRH and Lovage jobs still use `TRON 88x3.2`, and RRU jobs still use
  `TRON 88x2.5`.
