1. ISSUE SUMMARY & CONTEXT
--------------------------------------------------------------------------------
In calculation Job 537, the user configured 2 RRH models on the support mast:
  - 2x AHHB 2600

However, the Robot Worker only processed items[0] (AHHB 2600) and completely
ignored items[1] (AHDA 900).

IMPORTANT NOTE ON QUANTITY & PER-MAST DIMENSIONING:
The calculation is dimensioning ONE support mast (what is supported on one mast
for a sector). Having 6 total across 3 sectors means 2 per mast. The frontend
sends the per-mast quantity (e.g. qty: 2 for AHHB and qty: 3 for AHDA).
Robot must calculate Node 3 forces for 1 mast using these exact quantities.

3. ROBOT FEA MODELING - NODE 3 LOADS
--------------------------------------------------------------------------------
For every item in `rrh_equipment.items`:
  1. Look up catalog specifications (via `find_rrh_reference` or catalog dict):
     - `h_mm`, `w_mm`, `t_mm`: dimensions
     - `weight_kg`: unit weight
     - `cf_front`, `cf_lat`: drag coefficients (e.g. 1.36, 1.10)
     - `a_front`, `a_lat`: projected areas in m² (e.g. 0.10, 0.05)
  2. Compute forces for this item:
     - `weight_total_kg = round(qty * weight_kg, 2)`
     - `pe_dan = round(qty * weight_kg, 2)`
     - `fw_front = round(qty * cf_front * a_front * qp_dan, 2)`
     - `fw_lat = round(qty * cf_lat * a_lat * qp_dan, 2)`
     - `fw_front_formula = f"{qty} * {cf_front:.2f} * {a_front:.2f} * {qp_dan:.2f} = {fw_front:.2f} daN"`
     - `fw_lat_formula = f"{qty} * {cf_lat:.2f} * {a_lat:.2f} * {qp_dan:.2f} = {fw_lat:.2f} daN"`

  3. Aggregate across ALL RRH units mounted on this mast:
     - `TOTAL_WEIGHT_DAN = sum(item.pe_dan for item in rrh_items)`
     - `TOTAL_FW_FRONT_DAN = sum(item.fw_front for item in rrh_items)`
     - `TOTAL_FW_LAT_DAN = sum(item.fw_lat for item in rrh_items)`

  4. Apply to Robot Node 3:
     - Dead load (Cas 2 / PE):
         FZ = - TOTAL_WEIGHT_DAN
         (e.g., for 2x AHHB [31.4 daN] + 3x AHDA [42.0 daN] = -73.40 daN)
     - Wind X (Cas 3 & Cas 4 / Frontal Wind):
         FX = + TOTAL_FW_FRONT_DAN
     - Wind Y (Cas 5 & Cas 6 / Lateral Wind):
         FY = + TOTAL_FW_LAT_DAN
